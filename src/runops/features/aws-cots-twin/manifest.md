- **Completed phases:**
  - Prompt 0 — Project audit, guardrails, feature scaffold, route reservation, placeholder page
  - Prompt 1 — Typed data model, repository interface, in-memory demo repository, deterministic seed dataset
  - Prompt 2 — Page shell (header, business-service summary, responsive layout, URL-driven selection)
  - Prompt 3 — React Flow architecture canvas (nested boundaries, animated traffic, progressive-disclosure edges, health-encoded nodes, pan/zoom/fit/reset/minimap/fullscreen, click/double-click/edge selection, compact legend)
  - Prompt 4 — Reusable `ResourceHoverCard`: standardized hover on every canvas resource with lazy-loaded identity, per-type configuration, telemetry sparklines with thresholds, alert summary (with child-alert bubble-up so EC2 nodes surface attached EBS alerts), relationships tiles, operations, and 9 actions (Open Details functional, rest fire truthful "coming later" toast). Radix HoverCard with 220ms open / 140ms close, viewport-collision avoidance, keyboard focus support.
  - Prompt 5 — `ResourceDetailsPanel` with 12 tabs (Overview, Configuration, Telemetry, Alerts, Dependencies, Security, Cost, Changes, Incidents, Runbooks, Automation, Raw JSON). Persistent on desktop/tablet (≥768px) as a widened right-side panel; on mobile it opens as a full-screen shadcn `Sheet` drawer. Active tab is retained across resource selection changes. Close returns focus to the canvas container. Raw JSON is sanitized: `configuration.password/secret/token/credential/api_key/private_key/access_key/session/bearer/otp/ssn/email/phone/user_data` keys are replaced with `__redacted__`; Secrets Manager resources additionally strip any `value`/`payload`/`secret` configuration keys. Overview tab renders a computed health score, active-alert digest, business impact, operational readiness tiles, and top recommendations (driven off alert.recommended_action + patch/backup/compliance state). Telemetry tab supports 1h/6h/24h/7d/30d ranges with SVG line chart, threshold guides, anomaly markers, baseline/normal range/anomaly-score/freshness read-outs. Configuration tab renders a full drift table (attribute, current, desired, compliance, source, last changed, changed by, related change ID, drift flag) plus a 6-item history timeline. Dependencies tab renders separate upstream/downstream tables (protocol, port, status, latency, criticality). Alerts, Incidents, Changes, Security, Cost, Runbooks, Automation tabs all read from the repository layer.
