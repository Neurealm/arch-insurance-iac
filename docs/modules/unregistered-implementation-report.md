## Notable unregistered surfaces

- **Edge functions (25)** — all Supabase functions under `supabase/functions/`.
  None belongs to SRE; most map to `platform`, `commercial` or `cae`.
- **Carve-out route family (~70 routes)** — a large, coherent, entirely
  unregistered surface with no owning module and no shared layout.
- **`src/hooks/` (27 hooks)** — mixed platform, commercial and CRM concerns in
  one folder; folder location is not a reliable ownership signal here.

## Known limits of this report

- Ownership is inferred from route prefixes and source folders, both of which are
  weak signals in this codebase (the SRE module itself lives in `prod-twin/`).
- Dynamic imports built from template strings are not resolved by the import
  graph, so a small number of files may be reported with fewer consumers than
  they truly have. Any removal recommendation must be confirmed manually.
