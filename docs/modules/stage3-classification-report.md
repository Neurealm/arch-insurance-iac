implementation inventory (1,247 items). Every item receives exactly one disposition, a
confidence level and the evidence behind it. Nothing is guessed silently: an item that cannot be
dispositioned from evidence is recorded as `unable-to-determine` and flagged for human review.

## Review load

- 655 items are flagged `humanReviewRequired`.
- 367 items are `unable-to-determine`.

Every low-confidence disposition is flagged for review — this is asserted by
`src/modules/stage3.test.ts`.

## What the classifier will not do

- It will not infer ownership from a folder name alone when the folder is shared chrome.
- It will not classify an item as platform or shared unless the item matches a registered
  capability boundary in `src/modules/platform/` or `src/modules/shared/`.
- It will not mark anything deprecated. Deprecation is a product decision, not a code signal.
